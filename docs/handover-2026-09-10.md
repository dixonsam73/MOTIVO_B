## 2. THE LESSON THIS WORK PAID FOR — READ BEFORE THE NEXT UNIT

**Three one-of-N misses in one workstream, all the same shape:**
Unit 1b fixed one of two **publish** sites · Unit 1a fixed one of two **import**
sites · C-77's first repair fixed one of nine **extension-writing** sites.

Each was found by **device evidence, not review**, and each parity test I wrote
asserted the wrong functions until the next miss appeared. The answer was
structural: `AttachmentImportPolicy` now owns classification, refusal copy, the
allowed importer set **and the single extension decision**, with
`ImportPathParityTests` failing if a third import path or a second copy of the
extension rule appears.

**Before declaring any boundary complete: inventory every call site and assert
the count, not just the behaviour.**

Two other habits this window kept catching: **a source assertion that matches a
function's own declaration is vacuous** (it passed with the fix reverted), and
**always verify Release** — a `#if DEBUG` helper built clean in Debug and failed
Release.
