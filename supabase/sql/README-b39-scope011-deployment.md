**Generation.** All four are generated by `claude-evidence/scope012/gen_artifacts.py` from verbatim sources. **Never hand-edit; regenerate.** SHA-256 values are in the report.

**Submission form, required:** `supabase db query --linked "$(cat <artifact file>)"`, i.e. positional. This is the hosted route measured at CP-0 (2026-09-06): multi-statement text accepted; a raise aborts the whole submission; only the last statement's rows return; exit code 0 even on error.

**Why each artifact starts with `begin;`:** positional text that begins with a `--` comment is parsed as a CLI flag (`UnrecognizedOption`, before any SQL runs). Measured in rehearsal attempt 1.

**Not used:**
- **`-f`:** measured locally, the CLI sends the file as one prepared statement, and Postgres refuses multiple commands in one (attempt 2). Its hosted behaviour is unmeasured.
- **The local CLI:** it refuses multi-statement text in any form. The local rehearsal therefore submits the unchanged files through `psql -v ON_ERROR_STOP=1`, which stops at the first error so `COMMIT` never runs. That equals the hosted abort semantics **in effect**, not by the same code path, which is a stated limitation.

**Every file is ONE submission:**

`begin` → PRE guards → body → recompute → POST guards → `commit` → one read-only verification row.

**How guards behave:**
- Every abort-worthy check runs **before `COMMIT`**; a raise aborts the whole submission and changes nothing.
- **Cached-entitlement drift in PRE aborts.** It is assessed, never repaired by these files.
- **Scoring:** the response body only, never the CLI exit code, which is 0 on error. Success = a `s12_verification` row naming the artifact with `"committed": true`. Anything else is failure.

## 5. Stop rules

- **Response:** an error body or a missing verification row stops; do not retry with edited SQL. A retry is the same file only after the cause is understood.
- **Drift:** any PRE drift, md5 or comment mismatch is a production-drift finding for assessment. Do not weaken guards or adjust production.
- **Capture:** an H1/H2 difference before A1 stops.
- **Edge:** a version, download or `verify_jwt` mismatch stops.
- **Identity:** any cleanup schedule on the protected identity stops, and Samuel is told before anything proceeds.
